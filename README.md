# Linked List 🔗

A Kotlin implementation of **Linked List** data structure with node operations, Kotlin collection interface integration, and practical challenges.

> 📚 Built as a learning project following the **Data Structures & Algorithms in Kotlin** book by Kodeco (Ray Wenderlich).

---

## Features

- 📥 **Push** — insert at the head of the list
- 📎 **Append** — insert at the tail of the list
- 📌 **Insert After** — insert at a specific position
- 📤 **Pop** — remove from the head of the list
- ✂️ **Remove Last** — remove the tail node
- 🗑️ **Remove After** — remove a node at a specific position
- 🔄 **Kotlin Iterator & Iterable** — integrate with Kotlin's collection interfaces
- 🧩 **Challenges** — reverse a linked list, find the middle node, merge two sorted lists

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/M0bileDev/Algorithms_and_structures_LinkedList.git
   ```

2. Run the project:
   ```bash
   ./gradlew run
   ```

> **Note:** The default branch is `dev`.

## Purpose

This project was developed as a hands-on learning exercise to practice linked list fundamentals in Kotlin, covering node-based data management, head/tail operations, Kotlin collection interface conformance, and classic linked list challenges.
